# **Kapanin**
Sebuah aplikasi berbasis kecerdasan buatan yang membantu pemilik toko dalam 
menentukan waktu dan besaran diskon yang lebih tepat. Sistem akan memanfaatkan 
data historis penjualan, kondisi stok, pola permintaan, serta informasi terkait harga dan 
diskon untuk memprediksi kondisi penjualan produk.
